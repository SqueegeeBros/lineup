Download for Android
  1. Tap Download for Android.
  2. Open the downloaded file (tap the notification, or find it in My Files → Downloads).
  3. If your phone asks, allow installs from this source, then go back and tap Install.
  4. If Play Protect warns about an unknown app, tap More details → Install anyway. That shows for any app that isn't from the Play Store.

You only do this once. App updates come through automatically.
